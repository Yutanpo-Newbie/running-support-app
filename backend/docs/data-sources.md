# Data Sources

## 概要

本ドキュメントでは、ランニングサポートアプリのルート提案機能で利用する可能性のあるデータソースを整理する。

本研究では、ランナーにとって走りやすいルートを提案するために、以下の情報を扱うことを想定する。

- 道路ネットワーク
- 距離
- 信号数
- 交差点・分岐点数
- 高低差
- 車通り・交通混雑
- 歩道や道路種別
- 工事・通行止め・回避エリア

現段階では、これらの多くは仮データとして扱っている。  
今後、OpenStreetMap、OSMnx、Mapbox Trafficなどを段階的に導入し、実データに置き換えていく。

## OpenStreetMap

OpenStreetMapは、道路、歩道、建物、施設、信号、横断歩道などの地理情報を扱うオープンな地図データである。

本研究では、主に以下の情報源として利用する。

- 道路ネットワーク
- 道路種別
- 歩道の有無
- 信号情報
- 横断歩道
- 公園や歩行者専用道
- 施設情報

### 利用予定のOSMタグ例

| OSMタグ | 内容 | 本研究での使い方 |
|---|---|---|
| highway | 道路種別 | 幹線道路・生活道路・歩道などの分類 |
| footway | 歩道・歩行者用道路 | ランナーに適した道として評価 |
| path | 小道・遊歩道 | ランニング向き経路として評価 |
| sidewalk | 歩道の有無 | 車通りリスクの軽減要素 |
| crossing | 横断歩道 | 交差点・横断箇所の評価 |
| traffic_signals | 信号 | 信号数ペナルティに利用 |
| maxspeed | 制限速度 | 車通りリスク推定に利用 |
| lanes | 車線数 | 車通りリスク推定に利用 |

### 注意点

OpenStreetMapのデータは地域によって登録精度が異なる。  
特に信号、歩道、制限速度、車線数などは、すべての道路に登録されているとは限らない。

そのため、本研究では、OSMデータを絶対的な真値として扱うのではなく、ランナーにとっての走りやすさを推定するためのデータとして利用する。

## OSMnx

OSMnxは、OpenStreetMapから道路ネットワークや地理空間データを取得し、分析・可視化できるPythonライブラリである。OSMnxはNetworkXやGeoPandas上に構築され、OpenStreetMap APIと連携して道路ネットワークを取得・モデル化できる。  
参考：OSMnx公式ドキュメント、Getting Started。  

本研究では、OSMnxを以下の目的で利用する予定である。

- スタート地点周辺の道路ネットワーク取得
- 道路ネットワークのグラフ化
- ノード・エッジ情報の取得
- NetworkXによる経路探索
- ルート距離の算出
- 交差点数の推定
- 道路属性の取得

### 想定する処理

```text
1. スタート地点の緯度経度を受け取る
2. 指定半径内の道路ネットワークをOSMnxで取得する
3. スタート地点に最も近い道路ノードを取得する
4. 経由地点候補を複数生成する
5. NetworkXで start → waypoint → start の経路を求める
6. ルート候補を複数生成する
7. 各ルートをスコアリングする
